## Project Overview
Exploratory Data Analysis (EDA) is an important process in Data Science used to understand datasets, identify patterns, detect missing values, explore relationships between variables, and discover meaningful insights through statistical analysis and visualization.

This project performs EDA on the Palmer Penguins dataset using Python libraries to analyze penguin measurements, species distributions, missing values, correlations, and relationships between numerical features.

## Project Objectives
- Understand the structure and characteristics of the dataset.
- Identify missing values and duplicate records.
- Generate descriptive statistical summaries.
- Analyze categorical and numerical variables.
- Visualize data distributions using charts.
- Detect potential outliers using boxplots.
- Explore correlations between numerical features.
- Compare measurements across different penguin species.
- Extract meaningful insights through exploratory analysis.

## Analysis Performed

### Data Inspection
Examines dataset dimensions, column names, data types, and descriptive statistics.

### Missing Value Analysis
Identifies missing values in different columns to understand data quality.

### Duplicate Detection
Checks for duplicate records and removes exact duplicates from the analysis dataset.

### Univariate Analysis
Uses frequency counts and histograms to understand individual variables.

### Outlier Analysis
Uses boxplots to identify potential outliers that may require further investigation.

### Correlation Analysis
Uses a correlation matrix and heatmap to examine relationships between numerical variables.

### Species Comparison
Compares measurements such as body mass and flipper length across penguin species.

### Relationship Analysis
Uses scatterplots and pairplots to explore relationships among numerical features.

### Grouped Statistical Analysis
Calculates mean, median, standard deviation, and count for selected groups.
